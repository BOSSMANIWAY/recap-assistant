# Recap Assistant

AI-ассистент для записи встреч, транскрипции речи и управления компьютером
через голосовые команды. Один сервер, один порт — всё поднимается одной командой.

## Возможности

| Режим       | Статус      | Описание                                              |
|-------------|-------------|-------------------------------------------------------|
| Встречи     | готов       | Запись встреч, транскрипция, итоги, семантическая память (RAG) |
| Компьютер   | готов       | Голосовые команды терминалу (bash) с фильтром опасных  |
| Браузер     | в разработке* | Голосовое управление Chrome (агент на LLM)            |

*Вкладка «Браузер» в UI заблокирована и помечена звёздочкой — функционал
допиливается и будет доступен в следующих версиях.

## Архитектура

```
Браузер UI (:8099)  <── WebSocket ──>  FastAPI (main.py)
                                            │
                ┌───────────────┬───────────┴──────────┐
                │               │                      │
         Faster-Whisper     Ollama qwen3:8b      Browser Engine
         (ASR, локально)    (:11434)             (Playwright + Chrome CDP :9222)
```

При старте сервер сам поднимает Chrome с CDP; при Ctrl+C — всё останавливается.

## Требования

- macOS / Linux, Python 3.11+ (проект разрабатывался на 3.14)
- ОЗУ: от 8 ГБ (Whisper + локальная LLM)
- [Ollama](https://ollama.com/download) с моделью:
  ```bash
  ollama pull qwen3:8b
  ```
- Google Chrome (для браузерного режима)

## Установка

```bash
git clone https://github.com/BOSSMANIWAY/recap-assistant.git
cd recap-assistant

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# Playwright — для браузерного режима
.venv/bin/pip install playwright
```

Модель Whisper (`faster-whisper-small`, ~1 ГБ) скачивается автоматически
при первом запуске в каталог `models/faster-whisper-small/`.

## Запуск

```bash
.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8099 --log-level info
```

Открыть http://127.0.0.1:8099

Остановка — Ctrl+C (сервисы останавливаются автоматически).

## Режимы

### Встречи
1. Нажмите кнопку записи — начнётся стриминг аудио в Whisper.
2. Реплики появляются в чате в реальном времени, говорящие различаются
   по голосу (voiceprint).
3. По кнопке «Стоп» генерируются итоги встречи (сценарий выбирается в шапке:
   встреча, задачи, обучение, клиент и т.д.).
4. Все фразы и итоги попадают в семантическую память (ChromaDB) — ассистент
   учитывает прошлые беседы (RAG).

### Компьютер
Голос или текст превращается в bash-команду через LLM, команда выполняется,
результат возвращается голосовым/текстовым ответом. Опасные команды
(rm -rf, mkfs и т.п.) блокируются.

### Браузер (в разработке)
Голосовая задача автономному агенту в Chrome: «открой сайт и авторизуйся».
Пайплайн: речь -> планировщик (qwen3) -> Playwright/CDP -> действия на странице.
Механизм работает, но требует доработки надёжности — вкладка заблокирована.

## Структура проекта

```
recap-assistant/
├── main.py              # FastAPI: WS /ws/transcribe, REST API сессий
├── whisper_engine.py    # ASR на faster-whisper
├── llm_engine.py        # клиент Ollama + промпты итогов/подсказок
├── computer_control.py  # режим «Компьютер»: запрос -> bash -> ответ
├── browser_engine.py    # режим «Браузер»: локальный агент в Chrome
├── service_manager.py   # автозапуск/остановка Chrome CDP
├── memory_store.py      # RAG: ChromaDB + эмбеддинги Ollama
├── session_store.py     # SQLite: сессии, фразы, итоги
├── voiceprint.py        # кластеризация говорящих по голосу
├── audio_utils.py       # VAD-сборка фраз из PCM-потока
├── agent/               # планировщик браузерного агента
├── browser/             # контроллер Chrome (Playwright CDP)
├── prompts/             # системные промпты агента
├── static/              # SPA-интерфейс (vanilla JS, без сборки)
├── models/              # модели Whisper (не в репо)
├── recordings/          # WAV записей (не в репо)
└── memory_db/           # ChromaDB (не в репо)
```

## Переменные окружения

| Переменная        | По умолчанию | Назначение                       |
|-------------------|--------------|----------------------------------|
| OLLAMA_URL        | http://localhost:11434 | адрес Ollama            |
| LLM_MODEL         | qwen3:8b     | модель для ответов/итогов        |
| EMBED_MODEL       | nomic-embed-text | модель эмбеддингов RAG       |
| WHISPER_MODEL     | faster-whisper-small | модель ASR (в models/) |

## Данные (не версионируются)

- `sessions.db` — история сессий
- `recordings/` — аудиозаписи
- `memory_db/` — векторная память
- `models/` — веса Whisper
